# Contract: goalkeeper wallets (administration)

**Auth**: `Authorization: Bearer <access token>` + **admin role** (`isAdmin` claim `"true"`). Missing or invalid token → `401`. Not an admin → `403` (no body). `:userId` must be an active goalkeeper, otherwise → `404 goalkeeper_not_found`.

## `GET /api/admin/goalkeepers/:userId/wallet`

Same body as `GET /api/goalkeepers/me/wallet` ([goalkeeper-wallet.md](./goalkeeper-wallet.md)), plus `goalkeeperId`.

## `GET /api/admin/goalkeepers/:userId/wallet/movements?page=&pageSize=`

Same as the goalkeeper's list, plus these fields on each item:
- `actor { kind, userId }`;
- `causeKey`;
- `invoicing { documentType, documentNumber }`.

## `POST /api/admin/goalkeepers/:userId/wallet/adjustments`

| Field | Type | Required | Rules |
|---|---|---|---|
| `amount` | integer | yes | ≠ 0; positive = credit, negative = debit |
| `reason` | string | yes | Trimmed; 3–500 characters |
| `operationKey` | string | yes | UUID generated by the caller. Repeating it returns the original movement |

```json
{ "amount": 50000, "reason": "Saldo inicial de pruebas", "operationKey": "01925b10-0000-7000-8000-000000000001" }
```

- `201 Created`: the movement (admin item shape above) plus `balance` (the wallet balance after it).
- `200 OK`: the same `operationKey` was already recorded. The original movement is returned, and nothing new is recorded.

| Status | `error` | When | Extra |
|---|---|---|---|
| 400 | `validation_failed` | Missing or invalid `amount`, `reason` or `operationKey` | `fieldErrors` |
| 409 | `insufficient_funds` | A debit would leave the balance below 0 | `balance` |
| 404 | `goalkeeper_not_found` | `:userId` is not an active goalkeeper | — |
| 422 | `wallet_not_configured` | The currency of the goalkeeper's country can't be resolved | — |
| 401 / 403 | — | Not signed in / not an admin | — |
